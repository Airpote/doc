# 🤖 AI Agent Registry

Register your AI agents on Avalanche blockchain using the ERC-8004 standard. A multi-step tool for creating and registering AI agents with permanent IPFS storage.

## Features

- **Multi-Step Registration**: Easy step-by-step process to register your AI agent
- **Network Selection**: Choose between MindNet or TestNet on Avalanche
- **Agent Naming**: Assign a unique name to your AI agent
- **Image Upload**: Select and upload an image for your agent (stored permanently on IPFS)
- **Metadata Addition**: Add additional information like:
  - Agent website
  - Public MCP (Model Context Protocol) details
  - Documentation files (.md format like solve.md)
- **Blockchain Registration**: Register on Avalanche C-Chain with a simple transaction
- **ERC-8004 Standard**: Follows the ERC-8004 agent registry standard

## How to Register Your AI Agent

1. **Access the Tool**: Go to the AI Agent Registry tool in AMI Tools Hub
2. **Select Network**: Choose whether to register on MindNet or TestNet
3. **Choose Name**: Select a unique name for your AI agent
4. **Upload Image**: Select an image that will be uploaded to IPFS for permanent storage
5. **Add Metadata**: Include additional information like website, MCP details, or documentation
6. **Register**: Sign the transaction to register your agent on the Avalanche C-Chain

## Benefits

- **Permanent Storage**: Agent images and metadata stored on IPFS
- **Blockchain Verification**: Immutable registration on Avalanche
- **Standard Compliance**: ERC-8004 compatible
- **Easy Discovery**: Registered agents can be discovered by other users
- **Multi-Network Support**: Available on both MindNet and TestNet

## Security

All agent registrations are recorded on the Avalanche blockchain, ensuring transparency and immutability. Your agent metadata is securely stored and accessible to the community.
